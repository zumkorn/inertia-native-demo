# Inertia Native Demo

A small Rails web app to demonstrate how to use [Inertia](https://inertiajs.com) (React) with the [Hotwire Native](https://native.hotwired.dev) frameworks. The demo app is available at https://demo.inertia-native.dev.

## Running Locally

Clone the repo, and then:

```
$ bundle install
$ bin/dev
```

The server is running on [`localhost:3000`](http://localhost:3000). You can open that URL in the browser and ensure the native app is using the same URL.

## Requirements

* Ruby version defined in [`.ruby-version`](.ruby-version).
